# Skip SSL Warnings

Extensión para Google Chrome que permite omitir advertencias de certificados SSL vencidos, facilitando el acceso a sitios internos o de desarrollo.

## 🚀 Instalación

1. Descarga la extensión desde la [Chrome Web Store](enlace-pendiente)
2. O instálala en modo desarrollador:
   - Clona este repositorio
   - Ve a `chrome://extensions/`
   - Activa "Modo de desarrollador"
   - Haz clic en "Cargar extensión sin empaquetar"
   - Selecciona la carpeta `chrome-extension`

## 🔧 Uso

La extensión funciona automáticamente. Cuando encuentres un error de certificado SSL vencido, podrás continuar navegando sin interrupciones.

## 📋 Configuración

Haz clic derecho en el ícono de la extensión y selecciona "Opciones" para personalizar su comportamiento.

## 🔒 Privacidad

Esta extensión **no recopila, almacena ni transmite** ningún dato personal. Todo el procesamiento ocurre localmente en tu navegador.
